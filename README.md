# Sports Debrief

Upload a clip of yourself; get back a coach's debrief with one thing to fix.

What we're building and why: [docs/product-brief.md](docs/product-brief.md).

## Setup

Requires [uv](https://docs.astral.sh/uv/). After cloning, turn on the pre-commit hook that keeps video, frames and pose data out of this public repo:

```bash
git config core.hooksPath .githooks
```
